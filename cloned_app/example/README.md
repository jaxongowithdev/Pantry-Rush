# Tiny Chef 👨‍🍳

**Cook • Combo • Serve • Upgrade**

A fast-paced cooking and time management game built with Flutter and Flame engine.

## Getting Started

### Run the app:
```bash
fvm flutter run
```

Or without FVM:
```bash
flutter run
```

### Run on specific device:
```bash
fvm flutter run -d <device-id>
```

See the main README.md in the parent directory for full documentation.
