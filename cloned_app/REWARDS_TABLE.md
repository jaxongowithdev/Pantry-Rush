# Tiny Chef - Rewards Table

## 🎯 Coin System

Coins nhận được = **Base Reward × Quality Multiplier**

### Quality Multipliers:
- 🔥 **Perfect** (30-70%): **100%** của base reward
- ❄️ **Cold** (<30%): **60%** của base reward
- 💥 **Burnt** (>70%): **30%** của base reward
